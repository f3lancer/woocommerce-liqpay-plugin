Liqpay payment plugin for Woocommerce

Version: 0.1.1 beta

Woocommerce: <=8.2

Важливо! Плагін сумісний з WooCommerce до версії 8.3.0. Підтримка блокового редактора сторінок наразі в розробці.

Про плагін:
Додає інтеграцію платіжної системи LiqPay до вашого WooCommerce-магазину. Автоматично змінює статус замовлення залежно від результату оплати (успішна / неуспішна).
Підтримувані мови інтерфейсу: Українська, Англійська, Російська.

Як встановити:

Скопіюйте папку liqpay до директорії wp-content/plugins на вашому сайті.
Активуйте плагін через адмін-панель: WooCommerce → Налаштування → Платежі → LiqPay → Увімкнути.
Вкажіть публічний та приватний ключі LiqPay у налаштуваннях плагіна.
